# Танчики — расширенная браузерная версия

Загрузка на хостинг: распакуйте архив и положите `index.html`, `style.css`, `game.js` в одну папку (например, `public_html`). Сборка и сервер не нужны.

Возможности:
- стартовая заставка и главное меню;
- выбор из пяти карт/уровней;
- редактор карт с кирпичом, сталью, водой, травой и пустыми клетками;
- сохранение пользовательской карты и таблицы рекордов в localStorage браузера;
- режим на одного и двух игроков;
- сенсорные контролы для обоих игроков;
- клавиатура: игрок 1 — WASD/стрелки + Space; игрок 2 — IJKL + Enter;
- пауза, звуковые эффекты, враги разных типов, разрушаемые блоки.

Важно: редактор и рекорды хранятся локально в конкретном браузере/устройстве. Для общей онлайн-таблицы рекордов понадобится серверная часть.
