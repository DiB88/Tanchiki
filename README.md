# Танчики — браузерная аркада

Готовая мини-игра в духе классических 8-битных танковых аркад. Не требует сборки, сервера приложений или установки зависимостей.

## Запуск
1. Распакуйте архив.
2. Загрузите `index.html`, `style.css` и `game.js` в одну папку на хостинге.
3. Откройте `https://ваш-домен/` в браузере.

Можно проверить локально, просто открыв `index.html`.

## Управление
- Компьютер: WASD или стрелки — движение, пробел — выстрел, Esc — пауза.
- Телефон/планшет: экранный крестовик и кнопка «Огонь».
- Кнопка «Ⅱ» — пауза, «Звук» — включение/выключение звуков.

## Особенности
- Адаптивное поле и сенсорное управление.
- Враги нескольких типов, пули, разрушаемые кирпичные стены и стальные блоки.
- Защита штаба, жизни, уровни, бонусы и звуковые эффекты.
- Вся игровая логика работает на клиенте; внешние библиотеки не нужны.
